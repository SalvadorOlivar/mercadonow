# MercadoNow

## Vision

MercadoNow is a fictional digital commerce and delivery platform
focused on exploring the design and implementation of a scalable
billing system.

The project aims to simulate a real-world production environment
where orders, payments, invoices, refunds and merchant settlements
must be processed reliably.

## Main Goals

The project is designed to explore:

- Fullstack development
- Node.js and TypeScript
- React
- Clean Architecture
- SOLID principles
- Domain-driven design
- SQL and NoSQL databases
- Event-driven architecture
- Automated testing
- Observability
- CI/CD
- Docker
- Kubernetes
- AWS
- Infrastructure as Code

## Scope

The initial version will focus on the billing domain.

The system will allow:

- Creating orders
- Processing payments
- Generating invoices
- Processing refunds
- Calculating merchant commissions
- Generating merchant payouts

## Non-Goals

The project will not attempt to implement:

- Real payment processing
- Real food delivery
- Real logistics
- Real tax compliance
